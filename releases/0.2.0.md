# 0.2.0 - release notes / הערות גרסה

Release snapshot: 2026-10-22. Published after the matching PR passed CI.
תמונת גרסה: 22.10.2026. פרסום לאחר בדיקות ירוקות ומיזוג התיקון המתאים.

## עברית

- מפה המציגה בדיוק את השורות הגלויות בטבלה, עם גבולות תכניות חיים,
  אפשרות גלובלית להצגתם וטעינת תכנית יחידה. בחפיפה התכנית הקטנה ראשונה.
- סינון בקשות היתר פעיל; בקשות שנסגרו מוסתרות כברירת מחדל.
- תמונות תצוגה אוטומטיות לכל סקירת AI, תיקוני אייקון וגרפי סטטיסטיקה.
- שמירת התקדמות סריקה עמידה יותר וטיפול במיזוג תוצאות אחרי שינוי בענף הראשי.
- בדיקות רגרסיה לדפדפן וכלל המחייב קישור לבדיקה בכל תיקון באג.

האתר בלתי רשמי. תאריכי התנגדויות משוערים אינם אישור למועד הרשמי.
נתוני המקור, גבולות ושירותי המפה תלויים בזמינות הגופים המפרסמים.

## English

- Map follows the table's visible rows, with live plan boundaries, a global
  display option and single-plan loading. Smaller overlapping plans appear first.
- Permit filters work; closed requests are hidden by default.
- Automatic preview images for each AI review, icon fallbacks and statistics fixes.
- More durable scan checkpoints and publication handling when main advances.
- Browser regressions and required test evidence for every Bug fix.

This is an unofficial tracker. Estimated objection dates are not verified legal
 deadlines. Source data, boundaries and maps depend on the publishing services.
